# Vacancy Hunter v2

Локальный инструмент для поиска, фильтрации и первичной оценки вакансий на hh.ru.

Проект собирает вакансии по заданным поисковым запросам, отсеивает нерелевантные названия, загружает описания, оценивает соответствие спортивному и корпоративному профилю и формирует Excel-выгрузку с отчётом.

## Возможности

- Поиск вакансий на hh.ru по нескольким запросам.
- Фильтрация выдачи по названию вакансии.
- Загрузка описаний только у прошедших фильтр вакансий.
- Извлечение компании, зарплаты, локации, опыта, занятости и даты публикации.
- Оценка по двум профилям:
  - спортивное резюме;
  - корпоративное резюме.
- Расчёт итогового балла, приоритета и рекомендуемого резюме.
- Учёт коммерческих признаков и стоп-слов.
- Сохранение вакансий в SQLite.
- Экспорт в Excel.
- Генерация Markdown-отчёта.
- Пересчёт оценок без повторного поиска на hh.ru.

## Быстрый старт

### 1. Установка зависимостей

Создай виртуальное окружение и установи зависимости:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка поиска

Основные параметры находятся в `config.json`:

- город поиска;
- количество страниц;
- количество вакансий на страницу;
- фильтр опыта;
- график работы;
- минимальный балл релевантности;
- пути к базе данных, Excel и отчёту.

Поисковые запросы задаются в файлах:

```text
config/queries_sport.txt
config/queries_corporate.txt
```

Каждый запрос указывается на отдельной строке. Строки, начинающиеся с `#`, игнорируются.

### 3. Запуск поиска

```bat
run.bat
```

Перед запуском закрой Excel-файл, если он открыт.

После завершения будут созданы или обновлены:

```text
data/vacancies_test.db
output/vacancies_test.xlsx
output/report_test.md
```

### 4. Пересчёт оценок

Если изменились правила оценки, ключевые слова или стоп-слова, можно пересчитать уже сохранённые вакансии без нового поиска:

```bat
rescore.bat
```

### 5. Сброс тестовых данных

Для очистки тестовой базы, Excel и отчёта:

```bat
reset_test.bat
```

Скрипт удаляет только тестовые файлы:

```text
data/vacancies_test.db
output/vacancies_test.xlsx
output/report_test.md
```

## Как работает оценка

Инструмент оценивает каждую вакансию по двум направлениям:

| Профиль | Что учитывается |
|---|---|
| Спортивное | Спорт, спортивные проекты, мероприятия, соревнования, клубы, федерации |
| Корпоративное | Проекты, мероприятия, партнёрства, подрядчики, договоры, документооборот |

Дополнительно учитываются:

- коммерческие признаки: продажи, привлечение клиентов, спонсоров и партнёров;
- стоп-слова в названии;
- признаки нерелевантных технических, бухгалтерских, юридических и операционных ролей.

Итоговый балл рассчитывается так:

```text
спортивный балл + корпоративный балл - штрафы
```

Вакансия сохраняется в Excel, если её итоговый балл не ниже значения `min_score` из `config.json`.

## Результаты

### Excel

Файл `output/vacancies_test.xlsx` содержит только вакансии, прошедшие порог релевантности.

### Отчёт

Файл `output/report_test.md` содержит:

- общую статистику по базе;
- полноту извлечённых полей;
- распределение по рекомендуемым резюме;
- распределение по приоритетам и статусам;
- топ вакансий для рассмотрения;
- вакансии ниже порога;
- основания оценки и применённые штрафы.

## Важные ограничения

- Инструмент использует HTML-поиск hh.ru и не является официальным API-клиентом.
- Структура страниц hh.ru может измениться, из-за чего потребуется обновить селекторы.
- Балл является эвристической оценкой, а не гарантией соответствия опыту кандидата.
- Зарплата, опыт и стабильный оклад требуют ручной проверки.
- Не рекомендуется запускать поиск слишком часто, чтобы не создавать избыточную нагрузку на hh.ru.
